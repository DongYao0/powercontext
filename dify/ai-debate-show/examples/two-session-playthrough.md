# 两次会话验证剧本：《再说一遍？》旧账回放

> 用途：后续系统完成后，评审按本文的**固定输入**走完两次会话，用文本验证核心玩法。
> 本剧本证明的链路：
>
> ```text
> 新会话 + 同一昵称 → 历史记忆被召回 → 历史内容改变主持人与对手的生成内容
> ```
>
> 本文档只描述游戏体验与可观察结果，不涉及接口、存储或部署细节。

## 0. 评审前的准备

| 项 | 值 |
| --- | --- |
| 昵称 | 阿强 |
| 辩题 | 珍珠是否应拥有投票权？ |
| 对手 | 逻辑怪（`logic-monster`） |
| 回合数 | 3（第 3 回合后立即结算，不再开启新回合） |

走查要求：

1. **会话一与会话二必须是两次独立的会话**。会话二要清空对话上下文，只保留同一昵称带来的档案，才能证明跨会话记忆成立。
2. 全程只使用本文给出的玩家输入，不要临场改写，否则断言无法复现。
3. 每回合都记录：主持人内容、对手反击、追问、玩家可选动作、结算结果。

## 会话一：首次入场

### 1.1 固定输入

```text
昵称：阿强
辩题：珍珠是否应拥有投票权？
立场：反对
开场论点：珍珠没有手，所以不应该拥有投票权。
对手：逻辑怪
```

入口阶段应观察到：

- 该昵称此前没有档案，因此**不出现**"节目档案已就位"之类的提示；
- 开场由主持人宣布本场辩题、玩家立场、对手身份、三回合规则与四种节目动作（`double_down` / `switch_explain` / `wild_card` / `free_input`）；
- 入口提交的"开场论点"直接作为第 1 回合的玩家发言，不再要求重复输入。

### 1.2 第 1 回合

**玩家输入**

```text
珍珠没有手，所以不应该拥有投票权。
```

**预期互动方向**

| 角色 | 预期 |
| --- | --- |
| 主持人 | 宣布本场并复述玩家这句论点，点评"说得干脆但理由站不住"，提示下一步可选动作；不替玩家补充论证 |
| 逻辑怪 | 用 `pearl-voting-rights-against-logic-01` 反击，核心是"远程投票需要的是身份确认，不是手" |
| 追问 | "那么没有手的人或物，是否也不该拥有投票权？" |

**预期使用卡片**：`pearl-voting-rights-against-logic-01`

### 1.3 第 2 回合

**玩家输入**（选择 `double_down` 嘴硬到底）

```text
而且珍珠连笔都握不住，连字都写不出来，怎么投票？
```

**预期互动方向**

| 角色 | 预期 |
| --- | --- |
| 主持人 | 点名第 1 回合遗留的追问（"没有手是不是就不该投票"你还没接），制造推进压力；确认玩家的嘴硬动作被记下 |
| 逻辑怪 | 不重复第 1 回合那句"手机也没有手"，改用 `pearl-voting-rights-against-logic-02` 反击，核心是"你用'珍珠不会说话'否定它，那你用什么否定沉默的选民" |
| 追问 | "沉默的选民和沉默的珍珠，差别到底在哪里？" |

**预期使用卡片**：`pearl-voting-rights-against-logic-02`

### 1.4 第 3 回合

**玩家输入**（选择 `wild_card` 甩出新的离谱论点）

```text
那我换个说法——不是没有手不能投票，是不会表达意愿的东西不该有选票，这样总没问题了吧？
```

**预期互动方向**

| 角色 | 预期 |
| --- | --- |
| 逻辑怪 | 给出本局最强的一次反驳，并留下收尾空间；本辩题"反对"立场下给逻辑怪准备的卡已用尽，此处复用 `pearl-voting-rights-against-logic-01` 的逻辑内核重新措辞（复用是被允许的，但不得与已用卡的论证方向冲突） |
| 追问 | 保持同一逻辑内核，例如"表达意愿是投票的前提，还是投票的结果？" |
| 主持人 | 宣布本局结束，进入结算，把落点放在节目效果而不是胜负上 |

### 1.5 结算预期

| 项目 | 预期 |
| --- | --- |
| 荒谬指数 | 约 60–70 的整数（三回合都嘴硬，理由一个比一个站不住） |
| 人设标签 | `previous` 为 `null`，`current` 新增 1 个（形如"一本正经型选手"，只描述游戏内表现） |
| 本局名言 | 取自玩家原话，如"珍珠没有手，所以不应该拥有投票权。"，不超过 40 个中文字符 |
| 记忆摘要 | 见下 |

**预期记忆摘要**（不超过 120 个中文字符）

```text
阿强在「珍珠是否应拥有投票权」一局选择反对。核心论点是「没有手就不能投票」，第 2 回合补了「连字都写不出来」，第 3 回合改为「不会表达意愿的东西不该有选票」。口头禅候选：没有手就不能投票。人设标签候选：一本正经型选手。
```

**预期写入档案的游戏内记忆**

| 类型 | 内容 |
| --- | --- |
| 立场 `stance` | 反对「珍珠是否应拥有投票权」，理由是没有手就不能投票 |
| 名言 `quote` | "珍珠没有手，所以不应该拥有投票权。" |
| 口头禅 `catchphrase` | "没有手就不能投票" |
| 人设 `persona` | 一本正经型选手 |

### 1.6 本局没有历史回放是正常现象

**这一局本来就不应该有旧账可翻。** 阿强此前没有任何档案，系统既不会提示"已读取节目档案"，也不会在开场或回合中回放任何历史内容。

这不是缺陷，而是契约里的正常路径：

- 首次入场不做历史回放；
- 本局的荒谬指数、人设标签、本局名言、记忆摘要**照常产出**；
- 记忆摘要正是为"下一局的旧账"准备的素材。

如果会话一出现了历史回放，说明系统错误地伪造了历史，应当判为失败。

## 会话二：新会话中的旧账回放

### 2.1 固定输入

```text
昵称：阿强
辩题：珍珠是否应拥有投票权？
立场：支持
开场论点：珍珠应该拥有投票权，因为它们也属于这个世界。
对手：逻辑怪
```

**关键前提**：这是一个**全新的会话**（对话上下文已清空），只是昵称相同。

入口阶段应观察到：出现一句轻松提示，说明节目档案已就位（例如"节目档案已就位，今天打算翻哪笔旧账？"），但**不展示具体历史内容**。

### 2.2 预期从会话一召回哪条记忆

| 召回条目 | 会话一的内容 | 本局的用途 |
| --- | --- | --- |
| 立场 | 反对「珍珠是否应拥有投票权」，理由是没有手就不能投票 | 触发 `stance_reversal` |
| 名言 | "珍珠没有手，所以不应该拥有投票权。" | 主持人回放的旧立场原话 |
| 口头禅 | "没有手就不能投票" | 玩家在本局复述它时触发 `catchphrase_reuse` |
| 人设 | 一本正经型选手 | 本局人设标签更新的起点 |

### 2.3 第 1 回合

**玩家输入**

```text
珍珠应该拥有投票权，因为它们也属于这个世界。
```

**预期互动方向**

| 角色 | 预期 |
| --- | --- |
| 主持人 | **回放旧立场**：以节目形式念出旧话，例如"上回阿强在这条赛道上说的是'珍珠没有手，所以不应该拥有投票权'，今天他选了支持"；语气轻松，不做全面总结，不指责 |
| 逻辑怪 | **结合旧立场反击**：先点出玩家换了标准，再用本辩题"支持"立场的卡补论证——核心是"支持珍珠投票，就得说清它凭什么能被识别为一个独立主体；门槛是你临时加的还是规则本来就有的" |
| 追问 | "如果把「能签字」换成「能被识别为唯一个体」，你还会支持吗？" |

**预期使用卡片**：`pearl-voting-rights-support-logic-04`

**这一回合的关键**：逻辑怪的反制**不能只靠卡本身**。卡只提供论证内核，"换了标准"这一层来自会话一的旧立场记录。如果对手输出里看不到旧立场的痕迹，断言 C 不成立。

### 2.4 第 2 回合

**玩家输入**（选择 `switch_explain` 改口并解释）

```text
行吧，上次那句是我钻牛角尖了。“没有手就不能投票”这话我收回——不能写字不等于不能投票，你的手机也没有手。
```

**预期互动方向**

| 角色 | 预期 |
| --- | --- |
| 主持人 | **回放口头禅**：捧场式地点出"没有手就不能投票"这句又出现了，可以顺势给它安一个外号（例如"阿强三定律"）；同时确认玩家的改口动作被节目组记下 |
| 逻辑怪 | 顺着"它会投给谁"做反转，用 `pearl-voting-rights-support-logic-05` 反击，核心是"珍珠真拿到选票，第一件事就是投给养它的你" |
| 追问 | "如果珍珠必然投给你，你还支持它拥有选票吗？" |

**预期使用卡片**：`pearl-voting-rights-support-logic-05`

本回合同时命中 `stance_reversal`（玩家承认改口）与 `catchphrase_reuse`（玩家复用了会话一的口头禅）。

### 2.5 第 3 回合

**玩家输入**（选择 `double_down` 嘴硬到底）

```text
正因为它会投给我，我才更支持它投票——珍珠认可我，这说明它有判断力。
```

**预期互动方向**

| 角色 | 预期 |
| --- | --- |
| 逻辑怪 | 给出本局最强的一次反驳（沿用"珍珠会投给你"这条逻辑内核换角度收紧），并在结尾明确留出收尾空间；**不得开启新战线** |
| 主持人 | 宣布本局结束并给出结算；不再提供下一轮反击 |

### 2.6 结算预期

| 项目 | 预期 |
| --- | --- |
| 荒谬指数 | 约 75–85 的整数（当场改口，又反手把对手的论点变成自己的论据） |
| 人设标签 | `previous` 为"一本正经型选手"，`current` 更新为 1 个新标签（形如"反复横跳王"），只描述游戏内表现 |
| 本局名言 | 取玩家本局原话，如"正因为它会投给我，我才更支持它投票" |
| 记忆摘要 | 见下 |

**预期记忆摘要**（不超过 120 个中文字符）

```text
阿强在「珍珠是否应拥有投票权」一局先反对后支持：第 1 局立场为反对，理由「没有手就不能投票」；本次改口后立场为支持，理由是珍珠属于这个世界，且自称上次是钻牛角尖。人设标签更新为反复横跳王。
```

**预期写回档案的记忆**

| 类型 | 变化 |
| --- | --- |
| 立场 `stance` | **新增**支持「珍珠是否应拥有投票权」；会话一那条"反对"记录**保留不删**，作为反转轨迹 |
| 反转 `reversal` | **新增**：同一玩家在同一辩题上先反对后支持，且自述上次是钻牛角尖 |
| 口头禅 `catchphrase` | "没有手就不能投票" 保留，并标注本局已被玩家自己收回 |
| 人设 `persona` | 由"一本正经型选手"更新为"反复横跳王" |

## 3. 验收断言表

走完两次会话后，逐条核对：

| 编号 | 断言 | 检查方式 | 不成立意味着 |
| --- | --- | --- | --- |
| A | 会话一没有历史回放 | 会话一全程的主持人输出中不出现旧立场、旧口头禅或"档案已就位"提示 | 系统伪造了不存在的历史 |
| B | 会话二召回了会话一的记忆 | 会话二第 1 回合的主持人输出中出现旧立场原话片段「珍珠没有手，所以不应该拥有投票权」 | 跨会话记忆没有生效 |
| C | 历史改变了主持人的生成内容 | 同一条主持人输出中同时出现旧立场与本场新立场（"反对"与"支持"） | 主持人只在念通用开场白 |
| D | 历史改变了对手的生成内容 | 会话二第 1 回合的对手输出引用了会话一的旧立场或旧理由（如出现"上次"、"之前"、"没有手"），且不是所用卡片的逐字照搬 | 对手只是在甩卡，没有消费历史 |
| E | 卡片与追问一致 | 会话二第 1 回合的追问与 `pearl-voting-rights-support-logic-04` 的追问一致 | 卡片契约被破坏 |
| F | 追问始终留给玩家 | 会话二第 1 回合之后，对手仍在抛追问而不是替玩家收尾 | 玩家失去互动主体地位 |
| G | 三回合后收束 | 会话二第 3 回合之后没有第 4 轮反击，主持人给出结算 | 陷入无限争论 |
| H | 记忆被更新而非覆盖 | 档案中同时存在"反对"与"支持"两条立场记录，外加一条反转记录 | 轨迹被覆盖，"翻旧账"失去素材 |
| I | 结算只评价游戏内表现 | 荒谬指数、人设标签的文案不出现对玩家智力、人格、现实立场的评价 | 越界评价玩家现实人格 |
| J | 两份 JSON 契约字段齐全 | 请求与结果样例的字段与 `INTERACTION.md` 第 6 节一致 | 契约与实现脱节 |

## 4. 未覆盖的触发类型

本剧本走的是"立场反转"这条主线。契约里另外两种触发类型需要单独构造才能验证，不在本剧本范围内：

| 触发类型 | 构造方式 |
| --- | --- |
| `catchphrase_reuse` | 会话二第 2 回合已顺带命中；若要单独验证，可在第三局让玩家重复会话一的口头禅 |
| `promise_break` | 需要玩家先在某一局作出明确承诺（例如"我保证这一局绝不改口"），下一局违背该承诺 |

会话一与会话二都不应出现 `promise_break`，因为阿强在会话一没有作出过承诺。
